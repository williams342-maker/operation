# OpsWorkbench Control Center

OpsWorkbench is a security-focused operational control plane for discovering,
monitoring, and managing non-production application environments. The active
workspace lives in `control-center/`.

It includes authenticated administration, organization-scoped authorization,
audit logging, health and readiness reporting, agent capability discovery,
controlled configuration deployment, approval enforcement, backup and rollback
orchestration, and deterministic release packaging.

See `control-center/README.md` for development and validation instructions.
